# Adopters

Nobody is listed here yet, and that is the accurate state of this project rather than an
empty template nobody got round to filling.

**If you run PerspectiveGraph** - in production, in a pilot, or as the merge gate on one
repository - adding a line here is the single most useful thing you can do for the next
person evaluating it. An adopter list is the one claim a project cannot make about itself.

Open a pull request adding a row:

| Organisation | Since | How it is used | Contact (optional) |
|---|---|---|---|
| _example: Acme Ltd_ | _2026-09_ | _merge gate on the payments repos; weekly review of the path board_ | _@handle_ |

Rules, so that nobody has to think about them:

- **Only add yourself.** Nobody else may add your organisation, and a pull request adding a
  company by someone who does not work there will be closed.
- **Say only what you are comfortable saying in public.** "A European fintech" is a
  perfectly good row; so is a name with no contact.
- **Ask internally first.** Being named as a user of an attack-path tool is a disclosure
  about your own security programme, and that is a decision for your organisation rather
  than for the engineer who liked the tool.
- **Remove yourself any time**, by pull request or by asking - no explanation needed.

If you would rather not be listed but are willing to say what worked and what did not, an
issue or a private note is worth as much. What this project most needs is not a logo wall:
it is [a real environment's verdict on the paths it surfaced](CONTRIBUTING.md).
