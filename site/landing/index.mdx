## What it does

<CardGrid>
  <Card title="Joins what you already run" icon="puzzle">
    Trivy, Semgrep, Cloud Custodian and Falco findings, plus your AWS and Kubernetes state, in one
    graph of the environment as it really is. Cloud accounts are read, never written to.
  </Card>
  <Card title="Finds the way in" icon="magnifier">
    Every route from an internet entry point, through too much privilege, to a sensitive asset -
    ranked by what to fix first, each with how far its number can be trusted.
  </Card>
  <Card title="Stops it in the pull request" icon="github">
    The check goes red only when this change opens a route, names it, and the fix comes back as its
    own pull request to review and merge.
  </Card>
  <Card title="Says how far to trust it" icon="approve-check">
    It grades its own scores against real test outcomes, and says "not enough data yet" rather than
    make a verdict up.
  </Card>
</CardGrid>

![The dashboard's Today view: the routes being walked right now, what to fix first, and how far the scores can be trusted](/img/docs-screenshot-overview.png)

*The dashboard on sample scanner output, with synthetic test outcomes recorded so that every panel
has something to show - not a real environment. [The live demo](https://demo.a3thinker.it) runs the
same sample data with no outcomes at all.*

## What it does not claim

A score is what the model concludes from the evidence it was given, not a measured frequency.
Nothing has been calibrated against field data yet, and the engine says so itself -
[positioning](/positioning/) states what is claimed, what is not, and how to check.

Open source under Apache 2.0. It runs on your infrastructure and collects no telemetry.
[Contributions](/contributing/), [questions](/support/) and [a line in the adopters list](/adopters/)
are all welcome.
